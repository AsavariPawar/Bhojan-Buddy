# 🍽️ Bhojan Buddy – Smart Hostel Mess Food Planner

Bhojan Buddy is a web-based application designed to make hostel mess meal planning easier and more organized. It allows students to select their meals in advance and helps mess organizers manage daily menus and track student responses.

The main goal of this project is to reduce food wastage, improve meal planning, and make communication between students and mess organizers more efficient.

## 🌟 Features

- **Student Dashboard:** View the daily hostel mess menu.
- **Meal Selection:** Confirm or cancel meal choices.
- **Organizer Dashboard:** Publish and update menus for different meals.
- **Response Tracking:** View student meal selections in one place.
- **CSV Export:** Export meal response data for further use.
- **Firebase Integration:** Supports user authentication and cloud data storage.
- **Responsive Design:** Simple interface designed for convenient use on different screen sizes.

## 🎯 Project Objectives

- Reduce food wastage in hostel messes.
- Help students communicate their meal preferences in advance.
- Simplify daily menu management for mess organizers.
- Maintain organized records of student meal selections.
- Encourage smarter and more efficient food resource management.

## 💡 How It Works

1. Students register or log in to the website.
2. They view the published mess menu.
3. They confirm their meal choices or cancel a selection.
4. The mess organizer publishes menus and monitors student responses.
5. Response data can be exported as a CSV file for further analysis.
